# DRUM TRAINER

Persönlicher Drum-Trainingsplan mit PDF-Bibliothek.

## Features
- **Automatischer Trainingsplan** — Mo-SO mit wechselndem Fokus
- **PDF-Bibliothek** — 23 Drum-Bücher zum Durchblättern
- **Heutiges Workout** — Automatisch erkannt basierend auf Wochentag
- **Timer & Metronom** — Integriert im Workout-Bereich
- **Fortschritt** — Checkboxen (lokal gespeichert)

## Wochenstruktur
| Tag  | Fokus                    |
|------|--------------------------|
| MO   | Rudiments & Stick Control|
| DI   | Grooves & Funk           |
| MI   | Coordination & Indep.    |
| DO   | Jazz & Bop               |
| FR   | World Rhythms & Afro-Cuban|
| SA   | Solos & Application      |
| SO   | Technique & Review       |

## Deployment
Deployed via GitHub Pages — static HTML, kein Build-Tool nötig.
